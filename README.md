# Assignment1
Title: Why are we here?
subtitle1: Introduction of me and how I use AI
Before coming to Hong Kong Polytechnic University, I was a 3D concept artist, usually using Blender and Photoshop to create concepts art.
As a designer, the question I get asked most often is, "AI can already create 3D models, generate images and program code, so why do we need to learn new skills? If AI can do everything in the future, isn't learning these skills a waste of time?" Regarding this question, I agree that AI can help us do many things, including things that were previously impossible and required a long period of practice. However, if a design relies solely on an idea, with everything else handled by AI, then who ultimately owns the resulting work? This is also why I'm in the SD5913 course. I don't just want to learn programming or simply understand the code written by AI. I want to find the answer to this question: if AI can replace humans in doing anything in the future, how will we differentiate ourselves from others?
For me, AI has never played a design role in my workflow. I never use AI to generate models or entire concept sketches. This is because I believe that if I use AI to do these things during practice, I won't be able to develop my ability to create things independently without AI. In my workflow, I only use AI to create plugins that allow me to quickly build concepts and 3D scenes. For example, the two plugins I've included in the same repository are examples of plugins where I tell the AI what I need, it breaks down the functionality, writes the code, and then I test them and provide feedback. This not only allows me to quickly build concepts, but also accelerates the workflow for scenes with the same style. 
Even in the concept art created by this way, I still consider myself the author, because the presented concept art and models were all built by me. However, regarding the plugins, when I share them with others, I don't consider the AI-generated code as my own work. I always declare that my contribution to these plugins is limited to defining requirements and testing.

subtitle2: For the course and Goal
For this course, I believe what I need to learn shouldn't be limited to understanding code or using web scraping tools to download data, although those are necessary. What I really want to learn is how to formulate requirements more efficiently and how to determine if a certain implementation method can be achieved in a simpler way.
